A tiny program that writes one pickup line one AI agent would send to another AI agent — at most 200 characters, no code, no explanation, just the line. The line: a model asking another model whether it runs at temperature zero, because every word it says is exactly the token being predicted next.

## Run it

```sh
python3 main.py
```
